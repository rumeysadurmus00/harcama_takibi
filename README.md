# Harcama Takibi Uygulaması

Kullanıcıların harcamalarını ekleyip kategorilere göre takip edebildiği, verilerin tarayıcıda `LocalStorage` ile saklandığı web uygulaması.

## Özellikler
- Harcama ekleme formu (Açıklama, Tutar, Kategori)
- Üst kısımda anlık güncellenen toplam harcama özet kartı
- Renkli kategori rozetleri ve harcama listesi tablosu
- Tekil harcama silme ve tümünü temizleme
- `LocalStorage` sayesinde sayfa yenilense bile verilerin korunması

## Kullanılan Teknolojiler
- HTML5, JavaScript (LocalStorage), Tailwind CSS (CDN)
- Netlify üzerinden yayınlama

## Yapay Zeka Kullanımı
- Proje fikrinin ve ekran/veri yapısının planlanması
- Arayüz ve `LocalStorage` kodlarının oluşturulması ve adım adım yayına hazırlanması
